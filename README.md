# ระดับน้ำคลองประเวศบุรีรมย์ — หน้าเดียว ข้อมูลปัจจุบัน

รวมข้อมูลระดับน้ำปัจจุบันของคลองประเวศบุรีรมย์จาก
[ระบบตรวจวัดระดับน้ำ สำนักการระบายน้ำ กทม.](https://weather.bangkok.go.th/water/MapLetLeaf)
ไว้ในหน้าเดียว ไม่ต้องเปิดดูทีละสถานี (ไม่เก็บข้อมูลย้อนหลัง)

## เริ่มใช้งาน

```bash
pip install -r requirements.txt
python app.py
```

เปิด http://127.0.0.1:8050 (หรือดับเบิลคลิก `run.bat`)

## เปิดเป็น GitHub Pages

GitHub Pages เป็นเว็บแบบ static และเบราว์เซอร์อ่านข้อมูลจากเว็บ สนน. ตรงๆ ไม่ได้ (ไม่มี CORS)
จึงใช้ GitHub Actions (`.github/workflows/pages.yml`) ดึงข้อมูลทุก ~10 นาที แล้วสร้างหน้าเว็บใหม่:

1. `python build_static.py` → โฟลเดอร์ `site/` (index.html + data.json) — ทดลองในเครื่องได้ด้วย `python -m http.server -d site`
2. Actions อัปโหลด `site/` ขึ้น GitHub Pages
3. ภาพรูปตัดของแต่ละจุดโหลดสดจากเว็บ สนน. โดยตรง

ตั้งค่าครั้งแรก: ใน repo ไปที่ **Settings → Pages → Build and deployment → Source: GitHub Actions**

ข้อจำกัด: ตารางเวลาของ GitHub มักหน่วง 5–20 นาที และ GitHub จะปิด workflow ตามเวลา
อัตโนมัติถ้า repo ไม่มี commit ใหม่ 60 วัน (กดเปิดใหม่ได้ที่แท็บ Actions)

## หน้าจอ

1. **แผนภาพระดับน้ำตามแนวคลอง** (ภาพหลัก) — ข้อมูลเดียวกับกราฟ "ระดับน้ำ > คลองประเวศบุรีรมย์"
   ในหน้า MapLetLeaf: ระดับน้ำ ระดับควบคุม เตือนภัย วิกฤต และระดับน้ำด้านใน/นอกของประตูระบายน้ำ
2. **ภาพประตูระบายน้ำและระดับน้ำรายจุด** — ภาพรูปตัดจากหน้า StationDetail ของแต่ละสถานี
   เรียงจากตะวันตกไปตะวันออก พร้อมตัวเลขระดับน้ำ เกณฑ์ เวลา และลิงก์ไปหน้า สนน. คลิกภาพเพื่อขยาย

รีเฟรชอัตโนมัติทุก 5 นาที หรือกด "ดึงข้อมูลใหม่"

## แหล่งข้อมูล

| ข้อมูล | ปลายทาง สนน. |
|---|---|
| แผนภาพคลองประเวศ (ลำดับสถานี, ระดับน้ำ, เกณฑ์, ระดับควบคุม) | `POST /water/MapLetLeaf` (`selriver=30_1`) |
| ชื่อ เขต เวลา สถานะของสถานี | `POST /water/PageMap/GoogleMap` |
| ภาพรูปตัด/ประตูระบายน้ำ | `GET /water/StationDetail/CreateCrossection?id=…` |

ผลลัพธ์ถูกแคชไว้ 2 นาที (`CACHE_SECONDS` ใน `config.py`) เพื่อไม่ให้ยิงเว็บ กทม. ถี่เกินไป

## ปรับแต่ง (`config.py`)

- `EXTRA_STATION_IDS` — เพิ่มสถานีอื่นที่อยากดูในหน้าเดียวกัน ใส่รหัสจาก `StationDetail?id=…`
  เช่น `[29]` = ปตร.คลองแสนแสบ-บางชัน
- `PROFILE_RIVER_VALUE` — เปลี่ยนคลองของแผนภาพ (ค่าจาก dropdown ในหน้า MapLetLeaf)

## หมายเหตุ

ระบบอ่านข้อมูลจากหน้าเว็บสาธารณะของ กทม. หากหน้าเว็บเปลี่ยนรูปแบบ อาจต้องปรับ `bma_client.py`
ใช้เพื่อการติดตามเท่านั้น ไม่ใช่ประกาศทางการ
