## หน้าจอ

1. **แผนภาพระดับน้ำตามแนวคลอง** (ภาพหลัก) — ข้อมูลเดียวกับกราฟ "ระดับน้ำ > คลองประเวศบุรีรมย์"
   ในหน้า MapLetLeaf: ระดับน้ำ ระดับควบคุม เตือนภัย วิกฤต และระดับน้ำด้านใน/นอกของประตูระบายน้ำ
2. **ภาพประตูระบายน้ำและระดับน้ำรายจุด** — ภาพรูปตัดจากหน้า StationDetail ของแต่ละสถานี
   เรียงจากตะวันตกไปตะวันออก พร้อมตัวเลขระดับน้ำ เกณฑ์ เวลา และลิงก์ไปหน้า สนน. คลิกภาพเพื่อขยาย

รีเฟรชอัตโนมัติทุก 5 นาที (หรือโหลดหน้าเว็บใหม่)

## แหล่งข้อมูล

| ข้อมูล | ปลายทาง สนน. |
|---|---|
| แผนภาพคลองประเวศ (ลำดับสถานี, ระดับน้ำ, เกณฑ์, ระดับควบคุม) | `POST /water/MapLetLeaf` (`selriver=30_1`) |
| ชื่อ เขต เวลา สถานะของสถานี | `POST /water/PageMap/GoogleMap` |
| ภาพรูปตัด/ประตูระบายน้ำ | `GET /water/StationDetail/CreateCrossection?id=…` |

ผลลัพธ์ถูกแคชไว้ 2 นาที (`CACHE_SECONDS` ใน `config.py`) เพื่อไม่ให้ยิงเว็บ กทม. ถี่เกินไป

## ปรับแต่ง (`config.py`)

- `EXTRA_STATION_IDS` — เพิ่มสถานีอื่นที่อยากดูในหน้าเดียวกัน ใส่รหัสจาก `StationDetail?id=…`
  เช่น `[29]` = ปตร.คลองแสนแสบ-บางชัน
- `PROFILE_RIVER_VALUE` — เปลี่ยนคลองของแผนภาพ (ค่าจาก dropdown ในหน้า MapLetLeaf)

## หมายเหตุ

ระบบอ่านข้อมูลจากหน้าเว็บสาธารณะของ กทม. หากหน้าเว็บเปลี่ยนรูปแบบ อาจต้องปรับ `bma_client.py`
ใช้เพื่อการติดตามเท่านั้น ไม่ใช่ประกาศทางการ
